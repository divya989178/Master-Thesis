

# KATE VS LLMaAA
This repository consists of code for the Master's Thesis **"The Comparative Evaluation of Methods and Models for Multi-Label Classification of Historical Dataset"** 

The code for KATE and LLMaAA were adapted from [LLMaAA](https://github.com/ridiculouz/LLMaAA/tree/main) and [The Direct and Indirect Annotation](https://github.com/trister95/direct-and-indirect-annotation)

The repository has 3 folders and 3 code files and it is organized as follows:

### Results

This folder consists of the results for Gold and Silver standard training examples, Zero shot and KATE (direct), LLMaAA (indirect)

### Data

This folder consists of dataset split (demo/val/test) obtained from a JSON file (letters), knn-incontext examples, silver labels generated by llms for unlabeled dataset

### Indirect

This folder consists the code for indirect annotation and the following below summarizes the mechanics of the code file

4 Main functions(with sub functions): 

*Processor: Prepares the dataset for classification (tokenization but without attention mask and padding) for training the BERT models on annotated dataset by LLMs. Creates a file name Cache to store labeled data generated by LLMs. It is responsible for updating the cache file with newly classified samples and reloads the training data with newly classified samples

*Annotator: Uses both open-source model and closed-source models to classify(few-shot) unlabeled texts selected with the help of active learning strategy.

*Active learning strategy plus technique: It is responsible for managing the samples. Selects random samples initialy and sends it to classifier for sample.
Filters out the labeled samples from unlabeled ones and calculates uncertainity of labels using any of the active learning technique (CMN) to get top desired number of samples the model is not sure of and sends it to classifier

*Custom trainer: Model gets trained on LLMs generated labeled samples

*the main active learning loop: Implements all of the methods above

### Dataset Split

This file consist of code for data preprocessing and the dataset split on document level using binary frequency matrix

### Direct annotation
Uses few and zero shot technique on open-source model (Qwen and Mistral) and closed-source Models (Gemini and Claude) to classify the unlabeled training/test data using the libraries; outlines and pydantic to ensure strict format (JSON) of output generation.

### Gold and Silver Standard

Consists of code for BERT fine-tuning on gold and silver standard training dataset with hyperparameter optimization
